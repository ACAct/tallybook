# 轻记 · 个人记账本

一款在本机运行的中文个人记账软件。用浏览器操作，数据保存在本地 JSON 文件，不依赖云服务、账号或第三方 Python 库。

## 快速开始

需要 **Python 3.9 或以上**，以及支持 `<dialog>` 的现代浏览器。项目已在 macOS、Python 3.9.6 和本机浏览器验证；提供 Windows 启动脚本，Windows 尚未实机验证。

1. 解压项目，打开 `qingji` 文件夹。
2. 在该目录的终端运行：

   ```bash
   python3 app.py
   ```

   Windows 可使用 `py -3 app.py`，或双击 `start.bat`。macOS 可双击 `start.command`；若系统不允许直接运行，使用上方终端命令。
3. 浏览器会自动打开 **http://127.0.0.1:8765**。若没有自动打开，手动输入该地址。
4. 保持运行窗口打开。结束时按 `Ctrl+C`，已保存的数据仍在本地。

不需要 `pip install`，不需要 Node.js，也不需要联网。不能直接双击 `static/index.html` 使用，必须启动 Python 服务。

端口被占用时：

```bash
python3 app.py --port 8766
```

指定其他数据文件（适合演示）：

```bash
python3 app.py --data data/demo.json --port 8766
```

`--no-browser` 可关闭自动打开浏览器。默认数据路径始终相对项目目录，不受终端所在位置影响；自定义相对路径则相对终端当前目录。

## 已实现功能

| 功能 | 使用方式 |
| --- | --- |
| 记录收入、支出 | 点击「记一笔」，填写日期、金额、类别和可选备注 |
| 自定义类别 | 类别框既可选择，也可直接输入新类别，最多 30 字符 |
| 编辑、删除 | 在记录右侧使用编辑或删除按钮，删除前需确认 |
| 最近记录 | 总览按记账日期倒序展示最近 8 笔，同一天按创建时间排序 |
| 查看全部 | 「全部记录」每页 12 笔，可翻页 |
| 日期筛选 | 自选起止日期，或点击全部时间、本月、上月、今年 |
| 组合筛选 | 日期、收支类型、类别、金额区间和备注关键词同时生效 |
| 收支统计 | 总收入、总支出和结余，与当前筛选条件一致 |
| 图表 | 月度收支柱状图、支出类别环形图和类别明细表 |
| JSON 备份 | 「备份账本」始终导出完整账本，不受筛选影响 |
| JSON 导入 | 合并新记录，跳过完全相同的记录，存在冲突则整批取消 |
| CSV 导出 | 导出当前筛选范围的全部记录，不限于当前页 |

金额单位是人民币，输入必须大于 0、最多两位小数，单笔上限 99,999,999.99 元。日期和金额区间均包含上下边界；金额条件针对每笔金额的绝对值，收支方向由「类型」筛选。未来日期允许录入。账本上限 20,000 笔，JSON 导入上限 64 MiB。

筛选表单修改后点击「筛选」或在搜索框按回车生效；快捷日期按钮立即生效并保留其他条件。刷新页面会回到全部时间；已保存的账目不会丢失。「结余」指所选记录的收入减支出，不含期初余额。月度图显示筛选结果最近最多 12 个自然月；环形图将前五名之外的类别合并展示。

## 本地数据与恢复

- 正式账本：`data/ledger.json`，第一次保存时自动创建。
- 锁文件：`data/ledger.json.lock`，用于多个程序实例协调写入，请勿在运行时删除。
- 保存采用「事务锁 → 读取 → 校验 → 临时文件写入并刷新磁盘 → 原子替换」；无效输入不会改变账本。
- 损坏的 JSON 会显示错误并保留原文件，不会自动清空。恢复时先停止程序，将损坏文件另存保留，然后把正常备份复制为 `data/ledger.json`，再启动。
- 导入是合并，不覆盖现有记录。相同编号但内容不同会明确报错；需要整体恢复旧版本时，请按上一条停服替换文件。
- 数据是明文 JSON，保存在当前电脑用户可访问的目录；不提供加密、账号或多人权限。
- 服务仅监听本机 `127.0.0.1`，不用于公网部署。窄屏排版可以在电脑浏览器中测试；默认不会让手机通过局域网访问。
- `.gitignore` 已排除 `data/`，提交源代码时不会顺带提交默认位置的个人账目。

## 设计亮点

1. **金额精确**：使用 `Decimal` 校验输入，保存整数分，避免 `0.1 + 0.2` 带来的累计误差。
2. **保存可靠**：跨进程事务锁防止并发覆盖，原子替换减少半写文件风险，异常文件保留原样。
3. **易于理解和演示**：无第三方依赖，模块边界清晰；列表、统计和图表共用筛选结果。
