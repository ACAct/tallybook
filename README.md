# D2 · 页面结构与样式

| 项目 | 内容 |
| --- | --- |
| 所属层 | 前端（D） |
| 负责文件 | `static/index.html` `static/styles.css` |
| 负责区块 | 侧栏、汇总卡、筛选区、表格、图表容器、弹窗、toast、响应式、明暗主题 |
| 依赖 | D1（接口与静态资源路径） |
| 验收 | 手动浏览器验证 + 截图（无自动化） |

## 任务说明

实现语义化页面结构与样式：三视图布局、汇总卡、筛选面板、记录表格、图表容器、记账/确认弹窗，桌面/平板/窄屏响应式，以及明暗主题变量与表面色。

## 交付标准

- 提供 [`docs/接口契约.md`](../docs/接口契约.md) 第 6 节「前端 DOM 约定」列出的全部元素与 id（D3 依赖，id 不可改名）。
- 图标走 `sprite` 内的 `<symbol>`；金额/中文内容可读；窄屏可横向滑动表格。
- 主题支持 `data-theme="dark"`，配合 D3 切换。

设计参考见 [`docs/前端借鉴说明.md`](../docs/前端借鉴说明.md)。
